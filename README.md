# AI Git Assistant

A minimal VS Code extension foundation for Git assistance features.

## Development

```bash
npm install
npm run compile
```

Press `F5` in VS Code to launch the Extension Development Host, then run **AI Git Assistant: Hello World** from the Command Palette.

To open the interface, select **AI Git Assistant** in the Extension Development Host's Activity Bar. The Overview view is also available when no folder is open; it will prompt you to open a workspace.

The AI Git Assistant sidebar uses one integrated view with navigation for Overview, Changes, Commit, Branches, Conflict, History, Sync, AI Chat, and Settings. AI Chat and AI-generated commit messages require an AI provider, which is not connected by default.
